# Resources

## Official Documentation
- [WebXR Device API Spec](https://www.w3.org/TR/webxr/): Detailed explanation of the WebXR standard and its components.
- [MDN Web Docs - WebXR Device API](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API): Comprehensive guide and reference for the WebXR Device API.

## Tutorials and Guides
- [Three.js - How to create VR content](https://threejs.org/docs/index.html#manual/en/introduction/How-to-create-VR-content): Learn how to create VR experiences using Three.js and WebXR.
- [A-Frame School](https://aframe.io/): A series of tutorials and documentation for building WebXR experiences with A-Frame.
- [WebXR Fundamentals by Mozilla](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API/Fundamentals): Step-by-step guide to get started with WebXR, focusing on the basics and practical examples.
- [Bezi 101](https://www.bezi.com/bezi-101): Official tutorials for Bezi, a framework designed for building immersive WebXR experiences.
- [Spline Tutorials](https://spline.design/tutorials): Official learning resources for Spline, a design tool for creating interactive 3D web experiences.

## Online Courses
- [3D on the Web & WebXR](https://frontendmasters.com/courses/3d-webxr/): An introductory course on Frontend Masters covering the basics of WebXR.
- [Immersive Web Academy](https://immersiveweb.dev/): Free online courses and resources for learning immersive web technologies, including WebXR.

## Community and Forums
- [WebXR Slack Channel](https://webvr.slack.com/): Join the WebXR community on Slack to ask questions, share knowledge, and connect with other developers.
- [A-Frame Community](https://aframe.io/community/): Participate in the A-Frame community for support and collaboration on WebXR projects.
- [WebXR Subreddit](https://www.reddit.com/r/WebXR/): A subreddit dedicated to discussions and news about WebXR.

## Tools and Emulators
- [Immersive Web Emulator](https://chromewebstore.google.com/detail/immersive-web-emulator/cgffilbpcibhmcfbgggfhfolhkfbhmik): The Immersive Web Emulator browser extension lets you test your WebXR enabled pages on emulated Meta Quest devices.
- [WebXR Emulator Extension](https://github.com/MozillaReality/WebXR-emulator-extension): A browser extension that allows developers to emulate WebXR devices for testing purposes.

## Examples and Open Source Projects
- [WebXR Samples from the Immersive Web Working Group](https://immersive-web.github.io/webxr-samples/): Sample pages demonstrating how to use various aspects of the WebXR API.
- [Three.js Examples](https://threejs.org/examples/?q=webxr#webxr_vr_cubes): A collection of WebXR examples created with Three.js.
- [A-Frame Examples](https://aframe.io/aframe/examples/): A collection of WebXR examples created with A-Frame, showcasing different features and use cases.
- [Mozilla Mixed Reality GitHub](https://github.com/MozillaReality): Explore open source WebXR projects and examples maintained by Mozilla’s Mixed Reality team.
