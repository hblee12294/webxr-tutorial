# Resources

## Official Documentation
- [MDN Web Docs - WebXR Device API](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API): Comprehensive guide and reference for the WebXR Device API.
- [WebXR Explainer on GitHub](https://immersive-web.github.io/webxr/): Detailed explanation of the WebXR standard and its components.

## Tutorials and Guides
- [A-Frame School](https://aframe.io/): A series of tutorials and documentation for building WebXR experiences with A-Frame.
- [WebXR Fundamentals by Mozilla](https://mixedreality.mozilla.org/webxr-fundamentals/): Step-by-step guide to get started with WebXR, focusing on the basics and practical examples.
- [Three.js and WebXR - Basic Tutorial](https://threejs.org/examples/?q=webxr#webxr_vr_cubes): Learn how to create VR experiences using Three.js and WebXR.

## Books
- [Learning Web-based Virtual Reality: Build and Deploy WebVR Applications using A-Frame, Three.js, and WebXR](https://www.amazon.com/Learning-Web-based-Virtual-Reality-Applications/dp/1484249610): A comprehensive guide to creating WebXR applications using popular frameworks.
- [Programming 3D Applications with HTML5 and WebGL](https://www.oreilly.com/library/view/programming-3d-applications/9781449363959/): Though not solely focused on WebXR, this book covers essential 3D programming concepts relevant to WebXR development.

## Online Courses
- [WebXR - Introduction to Immersive Technologies](https://www.udemy.com/course/webxr-introduction-to-immersive-technologies/): An introductory course on Udemy covering the basics of WebXR.
- [Immersive Web Academy](https://immersive-web.dev/): Free online courses and resources for learning immersive web technologies, including WebXR.

## Community and Forums
- [WebXR Slack Channel](https://webvr.slack.com/): Join the WebXR community on Slack to ask questions, share knowledge, and connect with other developers.
- [A-Frame Community](https://aframe.io/community/): Participate in the A-Frame community for support and collaboration on WebXR projects.
- [WebXR Subreddit](https://www.reddit.com/r/WebXR/): A subreddit dedicated to discussions and news about WebXR.

## Tools and Emulators
- [WebXR Emulator Extension](https://github.com/MozillaReality/WebXR-emulator-extension): A browser extension that allows developers to emulate WebXR devices for testing purposes.
- [Chrome WebXR Developer Tools](https://chrome.google.com/webstore/detail/webxr-developer-tools/lcpwbdikcckepoijmgfggkjbicgfhobn): Developer tools for testing and debugging WebXR applications in Chrome.

## Examples and Open Source Projects
- [Mozilla Mixed Reality GitHub](https://github.com/MozillaReality): Explore open source WebXR projects and examples maintained by Mozilla’s Mixed Reality team.
- [A-Frame Examples](https://aframe.io/aframe/examples/): A collection of WebXR examples created with A-Frame, showcasing different features and use cases.
